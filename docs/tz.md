# Техническое задание: сайт RestoFood

## Назначение

Сайт ресторана, через который пользователь выбирает блюда из меню, собирает заказ в корзине, оформляет доставку и следит за статусом приготовления.

## Пользователь может

- посмотреть меню и найти блюдо по категории, цене, особенностям (вегетарианское, острое);
- открыть подробную информацию о блюде: состав, вес, калорийность, цену;
- добавить блюда в корзину, изменить количество, увидеть итоговую сумму;
- оформить заказ с адресом и способом оплаты;
- увидеть статус заказа: принят → готовится → передан курьеру → доставлен;
- узнать адрес, телефон, часы работы и написать в ресторан.

## Карта сайта

```
Главная ──┬── Меню ── Страница блюда ── Корзина
          ├── Корзина
          ├── Контакты
          └── О проекте
```

Меню в шапке на каждой странице: Главная, Меню, Корзина, Контакты, О проекте.

## Состав страниц

| Страница | Содержимое |
|---|---|
| Главная (`index.html`) | Заголовок с назначением сайта, кнопки «Смотреть меню» и «Моя корзина», 6 популярных блюд с картинками и ссылками на страницу блюда, три шага оформления заказа |
| Меню (`catalog.html`) | 14 блюд в виде карточек (картинка, название, категория, описание, цена, кнопка «В корзину»); панель фильтров (поиск, категория, цена от/до, вегетарианское, острое) и сортировка — работать начнут в ПР 2 |
| Блюдо (`dish.html`) | Хлебные крошки, крупное изображение, описание, цена, выбор количества, характеристики (вес, диаметр, калорийность, БЖУ, время приготовления), состав, «С этим часто заказывают» |
| Корзина (`cart.html`) | Состав заказа (блюдо, цена × количество, поле количества, сумма по позиции), блок «Итого» (сумма, доставка, к оплате), форма оформления (адрес, оплата, комментарий), статус заказа по этапам |
| Контакты (`contacts.html`) | Слоган, адрес, телефон, почта, таблица режима работы ресторана и доставки, форма обратной связи (имя, почта, тема, сообщение) |
| О проекте (`about.html`) | Описание проекта и план развития по практическим работам |
| 404 (`404.html`) | Сообщение об ошибке и ссылки на главную и меню |

## Набросок макета

```
Десктоп                                Телефон (360 px)
┌──────────────────────────────────┐   ┌──────────────┐
│ [лого] RestoFood     меню в ряд  │   │ [лого]       │
├──────────────────────────────────┤   │ меню в 2 ряда│
│ Заголовок + текст │  картинка    │   ├──────────────┤
├──────────────────────────────────┤   │ заголовок    │
│ [карт] [карт] [карт] [карт]      │   │ картинка     │
│ [карт] [карт]                    │   │ [карточка]   │
├──────────────────────────────────┤   │ [карточка]   │
│ подвал: о нас | контакты | меню  │   │ ...          │
└──────────────────────────────────┘   │ подвал       │
                                       └──────────────┘
Меню: фильтры слева (aside) + сетка карточек справа; на телефоне фильтры над списком.
Корзина: список позиций слева + блок «Итого» справа; на телефоне друг под другом.
```

## Требования к оформлению

- Общий файл стилей `css/style.css`, макет на Grid и Flexbox.
- Корректное отображение от 360 px без горизонтальной прокрутки.
- Тёплая палитра (оранжевый акцент `#c2410c`), контраст текста не ниже 4.5:1.
- Собственный логотип: вилка и ложка на оранжевом фоне.
