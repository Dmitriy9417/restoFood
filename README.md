# RestoFood — заказ еды из ресторана

Учебный проект по дисциплине «Введение в интернет-технологии».

**Вариант:** «Заказ еды из ресторана», группа «Заказ и бронирование».
**Особенность проекта:** состав заказа в корзине и статус приготовления заказа.

## Как запустить

Сборка и установка не нужны — это статический сайт.

1. Скачайте или склонируйте папку проекта.
2. Откройте файл `index.html` в любом современном браузере (двойной щелчок).

Можно также запустить простой локальный сервер из папки проекта:

```bash
python -m http.server 8000
```

и открыть в браузере `http://localhost:8000`.

## Структура

```
restoFood/
├── index.html      — главная: назначение сайта, хиты недели (6 блюд), как сделать заказ
├── catalog.html    — меню: 14 блюд, разметка фильтров и сортировки
├── dish.html       — страница блюда: фото, описание, характеристики, состав, цена
├── cart.html       — корзина: состав заказа, количество, итог, оформление, статус заказа
├── contacts.html   — контакты: адрес, телефон, режим работы, слоган, форма обратной связи
├── about.html      — о проекте (дополнительно)
├── 404.html        — страница ошибки (дополнительно)
├── css/style.css   — единый файл стилей для всех страниц
├── images/         — логотип, иллюстрации блюд (SVG)
└── docs/tz.md      — краткое техническое задание
```

## Что уже сделано (ПР 1)

- 7 связанных страниц, меню в шапке на каждой странице ведёт на все страницы.
- Семантическая разметка: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `address`, `figure`, `dl`.
- На каждой странице ровно один `h1`, уровни заголовков не пропускаются.
- У всех изображений заполнен `alt`.
- Указаны `charset="UTF-8"`, `lang="ru"`, мета-тег `viewport`.
- Стили только в `css/style.css`, атрибут `style` не используется.
- Макет на CSS Grid и Flexbox, абсолютного позиционирования для макета нет.
- Адаптивность: проверено при ширине 360 px — нет горизонтальной прокрутки, меню переносится и остаётся доступным.
- Доступность: у всех полей форм есть подписи `label`, видимый фокус при навигации клавишей Tab, контраст текста не ниже 4.5:1.
- Собственный логотип (`images/logo.svg`).

## Что будет дальше

- **ПР 2:** фильтры, сортировка и поиск в меню; добавление в корзину и пересчёт суммы; форма обратной связи на JavaScript; страница блюда по параметру `?id=`.
- **ПР 3:** сервер на FastAPI, база SQLite (блюда, заказы, пользователи), регистрация и вход, реальный статус заказа.
- **ПР 4:** Docker, хостинг, HTTPS.

Сейчас все ссылки «подробнее» ведут на одну страницу `dish.html` (пицца «Маргарита»); параметр `?id=` в ссылках заложен на ПР 2, когда страница станет заполняться данными.
